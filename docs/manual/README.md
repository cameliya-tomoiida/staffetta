# 受発注ハブ 操作の手引き

工場のスタッフ・事務の人が、毎日つかうための手引きです。
1ページに、作業は1つだけ書いています。写真の **赤い丸と番号** の順に押してください。

> 写真の会社名・お店の名前・数は、すべて架空です。
> 画面の左のメニューの並びは、写真と少しちがうことがあります。名前で探してください。

## 1日の流れ

```
朝 ─────────────────────────────────────────── 夕方
 ① 注文を確定する      ② 発注書を承認して送る      ③ 明日の製造計画を印刷する
  FAX・LINE・メール      仕入先へ                    現場にわたす
```

| いつ | やること | ページ |
|---|---|---|
| 朝 | FAX を見くらべて確定する | [1. FAX を確定する](01-fax.md) |
| 朝 | LINE・メール・サイトの「要確認」を確定する | [2. 受注一覧で確定する](02-orders.md) |
| 朝 | LINE のお客さんに「確定しました」を送る | [3. LINE の確定の連絡](03-line.md) |
| 昼まで | 発注書を見て承認する | [4. 発注書を承認する](04-purchase.md) |
| 昼まで | 承認した発注書を、FAX・サイトで送る | [5. 発注書を送る](05-outbound.md) |
| 夕方 | 明日の製造計画・工程表を印刷する | [6. 製造計画を印刷する](06-plan.md) |

画面のいちばん上の **「要確認」「FAX」「発注書」「注意」** の数が、のこっている仕事の数です。
ぜんぶ 0 に近づけば、その日の受注・発注はおわりです。

## 大事な決まり

- **AI（Claude）は読み取って「要確認」の印をつけるまで。** 数を直す・確定するのは人です。
- **発注書は、人が承認するまで送りません。** 送るのも人です。
- 確定・承認のときは、かならず **自分の名前** をえらんでください。だれが確定したか、記録にのこります。
- 写真のつくり直し：`python scripts/manual/annotate.py`（元の写真を足すときは、実在の会社が写っていないか目で確かめる）
