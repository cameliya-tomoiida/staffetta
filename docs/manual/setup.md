# 導入のしかた（新しい工場で使い始めるとき）

[← 目次](README.md)

新しい工場で受発注ハブを使い始めるときの順番です。全部で **4つの段階** です。
上から順に進めてください。前の段階のデータを、あとの段階が使います。

| 段階 | やること | 目安 |
|---|---|---|
| 1 | マスタの CSV を、順番に入れる | 1〜2日 |
| 2 | FAX の転送を設定する | 1時間 |
| 3 | LINE 公式アカウントをつなぐ | 1時間 |
| 4 | 1週間ためて、FAX の様式を承認する | 1週間 |

> ログイン・アカウント作成・規約への同意・パスワードの入力は、**工場の担当の人が自分で** 行います。
> 合いかぎ（トークン・シークレット）は `.env.local` にだけ書き、人に見せたり、チャットに貼ったりしません。

---

## 段階1　マスタの CSV を順番に入れる

マスタは、ほかのマスタを使っています（例：材料は「どの仕入先から買うか」を使う）。
**使われる方から先に** 入れます。やり方は [7. CSV で一括登録](07-master-csv.md) と同じです。
各マスタの画面の **「空のテンプレート（見出しだけ）」** で見出しだけの CSV を出し、Excel で書いてから読み込みます。

| 順番 | マスタ（左のメニュー） | 先に入っている必要があるもの |
|---|---|---|
| 1 | 仕入先 | なし |
| 2 | 仕入先の便（締め・届く日） | 仕入先 |
| 3 | 材料 | 仕入先 |
| 4 | 包材 | 仕入先 |
| 5 | ライン・設備・班と人数 | なし |
| 6 | 生地 | ライン |
| 7 | 配合（1行ずつ） | 生地・材料 |
| 8 | 工程・工程ごとの配置 | 生地・設備 |
| 9 | 商品 | 生地・仕入先 |
| 10 | 商品の包材・トッピング | 商品・包材・材料 |
| 11 | 配送の便（出発時刻・走る曜日） | なし |
| 12 | 取引先（CSV で一括） | 配送の便 |
| 13 | 定期注文 | 取引先・商品 |
| 14 | 取り込みの設定（シート・専用サイトのコード表など） | 取引先・商品 |

- 1つ入れるたびに、**エラーが 0 か** を確かめてから次へ進みます。
- 入れおわったら、**製造計画・工程表** で明日の分を出してみて、生地の量・時刻がおかしくないか、製造の責任者に見てもらいます。
- 今のデータは、**バックアップ** の画面で、いつでも書き出せます。

## 段階2　FAX の転送を設定する

```
複合機 ──PDF──▶ FAX 用のメール（Gmail）──1分おき──▶ 受発注ハブの FAX受信箱
```

1. 複合機の設定で、受けた FAX を **PDF にして、FAX 用のメールアドレスに転送** します（複合機の説明書を見てください）。
2. FAX 用の Gmail で、転送の小さなプログラム（`gas/fax-forwarder.gs`）を動かします。手順は [Gmail の設定](../gmail-setup.md)。
3. 外からハブに届くように、トンネルを用意します。手順は [トンネルの設定](../tunnel.md)。
4. 複合機にテストの FAX を送り、1〜2分で **FAX受信箱** に出ることを確かめます。

- 転送のプログラムは、メールを読むだけです。メールを消したり、既読にしたりしません。
- 設定した時刻より前の FAX は、ハブに入りません（古い FAX が流れこまない）。

## 段階3　LINE 公式アカウントをつなぐ

手順は [LINE 注文の設定](../line-setup.md) にあります。大きな流れは、

1. LINE 公式アカウントを作り、Messaging API を使えるようにする
2. 合いかぎ（チャネルシークレット・アクセストークン）を `.env.local` に書く
3. Webhook（LINE からハブへの入口）の URL を入れる。自動の返事は止める
4. 注文フォーム（LIFF）を作り、リッチメニュー（トークの下のボタン）を出す：`node scripts/line-richmenu.mjs`
5. お客さんに [LINE でのご注文のしかた](customer-line-order.html) を印刷してわたす（QR を貼り、締め切りの時刻と休みの曜日を書く）
6. はじめて注文してきた人を、**取引先** の画面でお店にひも付ける

## 段階4　1週間ためて、FAX の様式を承認する

取引先ごとに、FAX の注文書の形（様式）がちがいます。ハブは **はじめての様式を、人が承認するまで受注に入れません。**

1. 使い始めの **1週間** は、ふだんどおり紙でも受注しながら、FAX をハブにためます。
2. FAX受信箱で FAX を開くと「新しい様式・承認待ち」と出ます。
3. 読み取りの結果（お店・品名・数）が元の FAX と合っているかを見て、**様式を承認** します。
4. 承認した様式は、次から自動で読み取ります。品名と商品の対応も覚えていくので、使うほど正確になります。
5. 承認した様式の一覧は、マスタ管理の **FAX の様式** で見られます。

1週間で、よく来る取引先の様式がそろいます。そろったら、紙の受注をやめて、[1日の流れ](README.md#1日の流れ) に切りかえます。
