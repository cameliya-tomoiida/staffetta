# STAFFETTA スマホ版の決まり（⑧・2026-11-06 案）

手本は2つです。どちらも担当者が「使いやすい」と言っている、同じ会社のアプリです。

- 配送スタッフの在庫入力アプリ（オフィス自社）
- パチンコの分析アプリ

この2つの作りを、STAFFETTA のスマホ版にそのまま使います。
**スマホ = 幅 768px 未満**です。768px 以上（タブレット・パソコン）の見た目は今のままにします。

## 1. 画面の形

- **上は細い帯だけ**にします（11/6 夜に作り直し。写真は docs/screenshots/mobile-v2/）。
  - 中身は「‹ 戻る（または印）」「画面の名前」「AI に頼む」「≡ メニュー」です。
  - **メニューは右上に、文字つきのボタン**で出します（前は下のタブの右端で、気づきにくかった）。
  - 帯は上に貼りつけ、少しすける（ぼかし）地にします。iPhone の上の切り欠き（safe-area-inset-top）の分は、すき間をあけます。
- **下のタブは浮いた形**にします。
  - 左右 12px・下はホームのバー（safe-area-inset-bottom）の上 8px に置きます。layout の viewport に viewportFit: "cover" を入れて、env(safe-area-inset-*) を効かせます（入れないと 0 のままで、ホームのバーとかぶる）。
  - 4つまでで、SVG の絵と短い文字を出します。今いるタブは、絵の後ろの丸い面（うすい椿の赤）と太字にします。
- **下タブは役割ごと**に変えます。

  | 役割 | 下のタブ |
  |---|---|
  | 管理者 | ホーム／注文／製造／お知らせ |
  | 事務 | ホーム／注文／FAX／お知らせ |
  | 工場 | ホーム／製造計画／製品カード／衛生 |
  | 配送 | 配送の画面に自前のタブ（共通の下のタブは出さない） |

- **右上の「メニュー」を押すと、全部の画面の一覧が下から出ます**（シート）。
  - まとまりの見出しも、ボタンの形にします。
  - 上に、名前でさがす窓を置きます。
- **ホームは「今日やること」のカード**にします。数のあるものを上から（急ぎ → 要確認 → FAX → 発注書 → 材料不足 → 注意）、大きな数字・控えめな文字・右に「›」。押すとその仕事へ。0件のものは下に小さな丸い札でまとめます。色は 赤＝急ぎ・黄＝確かめる だけ。
- **文字を入れているあいだは、下タブを隠します**（キーボードに押し上げられないようにするため）。
- 「今日の仕事」の数字の帯（急ぎ・要確認・FAX…）は、**横にスクロールする1行**にします。
- 本文は1列にします。左右のすき間は 16px です。下タブに隠れない分、下をあけておきます。

## 2. 押す所・文字

- **押せる所は 48px 以上**にします。ボタンのあいだは 8px 以上あけます。
- **本文の文字は 16px 以上**、**数字は大きく**します。入力欄も 16px 以上にします（iPhone で勝手に拡大されないため）。
- **補足の字を薄い灰色にしません**。焦げ茶（今の ink-soft）以上の濃さにします。
- **押して開く所は、ボタンに見せます**。
  - 「タップで〜」のような小さい字はやめます。
  - 枠つきのボタンに › を付けて、開くと › が回るようにします。
  - たたむ見出し（details）も、全部ボタンの形にします。
- **絵文字は使いません**。アイコンは SVG にします。
- **選ぶものは、大きなボタンを並べます**（select はやめる）。
  - よく使うものを上に出し、「すべて見る」と名前でさがす窓を付けます。
  - 数が多いもの（取引先など）は、さがす窓を上に置きます。
- **ダブルタップで拡大しない**ようにします（touch-action: manipulation）。

## 3. 一覧と表

- **表は、スマホではカードの一覧にします**（横スクロールの表はやめる）。
  - カードの1行目は名前を大きく、2行目に大事な数字を2〜3個並べます。
  - 押すと、くわしい画面か、下から出るシートが開きます。
- 表がどうしても要る所（工程表・製品カードの記入など）は、**左の列（名前）を止めて横にスクロール**します。
- **長いものは、最初の8件＋「すべて見る」**にするか、タブに分けます。
- 一覧の上には、**さがす窓**を置きます。
- **押した行は一瞬光ってから、次へ進みます**（押した感を出す）。

## 4. 入力

- 入力の画面は**1列**にします。ラベルは欄の上に置きます。
- 数は大きな ＋ − か、数字のキーボード（inputmode="numeric"）で入れます。
- **日付は ‹ › で前後の日、日付を押すとカレンダー**が出ます。日付は大きく出します。
- 保存のボタンは、画面の下に大きく置きます（下タブの上）。

## 5. 画面の移動

- 画面の移動は、**ブラウザの履歴に積みます**。スマホの戻るでも、上の ‹ でも、1つ前に戻れます。
- くわしい中身は**下から出るシート**で見せます。シートの外を押すと閉じます。
- 画面は、**ふわっと横から入ります**（短く 0.2 秒）。
- 長い説明はたたんでおきます。

## 6. 色・形（今の決まりのまま）

- 色は**椿の赤＋白**です（デザイン_Codex の 02_tokens.css／今の globals.css の crust・ink・rule）。
- カードは白で、角は丸く、枠は細くします。大事なボタンは赤い地に白い字にします。
- スマホがダークモードでも、明るい色のままにします。

## 7. 先に作る画面（11/7 夕方まで）

1. 外枠：上の帯・下タブ・メニューのシート・入力中に下タブを隠す・数字の帯を横スクロールに
2. ホーム（役割ごと）・AI に頼む（下から出る全画面のシート）
3. 配送（/driver。① の画面なので、触るのは見た目だけ）
4. 製品カード・衛生の入力（スマホとタブレット）
5. 表の画面を、カードの一覧に（注文・取引先・商品・発注書・製造計画・マスタ）

**確かめ方**：375px（iPhone）・768px（タブレット）・パソコンの3つで写真を撮ります。375px は、前と後を並べて見せます。
