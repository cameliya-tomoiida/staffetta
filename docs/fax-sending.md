# こちらから FAX を送る方法（案）

対象：油の問屋（デモでは「みなみ油糧」「米田製粉」）など、FAX で発注している仕入先。
複合機：工場の複合機（FAX の機能・アプリを足せるしくみあり。インターネット FAX の追加の部品はなし）。

## いまハブでできていること（デモで見せる流れ）

1. `/outbound` で、発注書の下書き（③の計算）を人が「承認」する。承認は③の `approvePurchaseOrder` で記録される（誰が・いつ）。
2. 承認と同時に FAX 用の発注書 PDF ができ、画面上の「📠 FAX 送信待ち」一覧に入る（送り先の FAX 番号・PDF・承認者が並ぶ）。
3. 「複合機から送信（デモ）」ボタンは **ダミー**。押しても何も送らず、状態も変えない（下の案のどれかをつないだら本物にする）。
4. 人が複合機から送ったあと「送った」を押すと、③の `markSent` で送信済みになる（承認していない発注書は送信済みにできない）。

ハブは自分では FAX を送らない。送るのは人。**複合機の設定は変えていない。**

## 送り方の案

| 案 | やり方 | よいところ | 気になるところ |
|---|---|---|---|
| **A. 紙で送る（今すぐできる）** | PDF を印刷して、複合機の FAX で送る | 設定変更なし。今日からできる | 印刷と番号入力の手間が残る |
| **B. ネットワーク FAX ドライバー（おすすめ・第1段階）** | 事務所の PC に複合機メーカーの「ネットワーク FAX ドライバー」を入れる。ハブの PDF を開いて「印刷」→ プリンターに FAX ドライバーを選ぶ → 送信設定で宛先番号を入れて送信。PDF は画像として LAN 経由で複合機に渡り、複合機の FAX 回線から出る。FAX System 12 の使用説明書に「PC からの FAX 送信」の章がある | 紙がいらない。今の FAX 回線のまま。月額費用なし | 送信に使う PC ごとにドライバーの導入が必要。複合機側で「ネットワーク FAX」を受け付ける設定になっているかの確認が必要【要確認】。宛先番号は人が入れる（ハブの画面に番号を出しておく） |
| **C. メール→FAX サービス（第2段階）** | 外部の「メールで送ると FAX にして届けてくれる」サービスを契約。ハブが承認後に、そのサービスあてのメール下書きを作る（送信は人）。サービスによっては API で送れる | 複合機を通さない。送信結果（成功・失敗）が記録に残る | 月額・1枚ごとの費用がかかる。送信元の FAX 番号の表示が今の番号と変わることがある【要確認】 |
| D. HyPAS アプリ | 複合機に HyPAS 対応のアプリ（FAX サーバー連携の製品など）を入れて送る | 複合機の画面から送れる | 調べた範囲では、HyPAS の FAX 系アプリは「FAX サーバーにつなぐ」ものが中心で、共有フォルダの PDF をそのまま FAX する標準の機能は見つからなかった。対応アプリと費用は販売店に確認が必要【要確認】 |

## おすすめ

- **デモ（11/6 の動画）**：今のまま「承認 → PDF ができて送信待ちに入る」まで。
- **本番の第1段階**：B（ネットワーク FAX ドライバー）。ハブの「FAX 送信待ち」に宛先の FAX 番号と PDF を並べておき、人が印刷メニューから送る。送ったら「送った」を押す。
- **第2段階**：送る数が増えたら C を検討。承認ボタンのあとに、人がもう一度「送信」を押したときだけ送る形にする（承認なし・人の操作なしでは送らない、という決まりは守る）。

## 作者にお願いすること（決めたあと）

- B にする場合：販売店（または社内の担当）に、ネットワーク FAX ドライバーの入手と、複合機側の設定の確認を頼む。**複合機の設定変更は、作者の了承を取ってから行う。**
- C にする場合：サービスの選定と契約（課金が発生するので作者の判断）。

## 調べた資料

- 複合機の FAX の説明書の「PC から FAX を送る」の章（正式には複合機メーカーの説明書で確かめる）
- 複合機のネットワーク FAX ドライバーの説明（送信に使う PC すべてにドライバーが必要、LAN 経由で画像として送る）
- HyPAS 対応の FAX サーバー連携製品の例（XMediusFAX Connector）：https://www.abstech.com/wp-content/uploads/kyocera-software-document-management-xmediusfax-connector-data-sheet.pdf
