# こちらから FAX を送る方法（案）

対象：油脂の仕入先など、FAX で発注している仕入先。
複合機：プリンター 見本プリンター（FAX System 12 あり、Internet FAX Kit なし、HyPAS あり）。

## いまハブでできていること

1. 発注書の下書きを人が「承認」すると、FAX 用の発注書 PDF ができる。
2. その発注書は「FAX 送信待ち」に入る（`/outbound` 画面）。
3. 人が複合機から送ったあと、「送った」を押すと送信済みになる。

ハブは自分では FAX を送らない。送るのは人。

## 送り方の案

| 案 | やり方 | よいところ | 気になるところ |
|---|---|---|---|
| **A. 紙で送る（今すぐできる）** | PDF を印刷して、複合機の FAX で送る | 設定変更なし。今日からできる | 印刷と番号入力の手間が残る |
| **B. ネットワーク FAX ドライバー（おすすめ・第1段階）** | 事務所の PC にプリンターの「ネットワーク FAX ドライバー」を入れる。ハブの PDF を開いて「印刷」→ プリンターに FAX ドライバーを選ぶ → 宛先番号を入れて送信。複合機の FAX 回線から出る | 紙がいらない。今の FAX 回線のまま。月額費用なし | PC へのドライバーの導入が必要。複合機側で「ネットワーク FAX」を使える設定になっているかの確認が必要【要確認】。宛先番号は人が入れる（ハブの画面に番号を出しておく） |
| **C. メール→FAX サービス（第2段階）** | 外部の「メールで送ると FAX にして届けてくれる」サービスを契約。ハブが承認後に、そのサービスあてのメール下書きを作る（送信は人）。サービスによっては API で送れる | 複合機を通さない。送信結果（成功・失敗）が記録に残る | 月額・1枚ごとの費用がかかる。送信元の FAX 番号の表示が今の番号と変わることがある【要確認】 |
| D. HyPAS アプリ | 複合機に HyPAS のアプリを入れて、共有フォルダの PDF を FAX 送信する | 複合機だけで完結 | 対応するアプリがあるか、費用は販売店に確認が必要【要確認】 |

## おすすめ

- **デモ（11/6 の動画）**：今のまま「承認 → PDF ができて送信待ちに入る」まで。
- **本番の第1段階**：B（ネットワーク FAX ドライバー）。ハブの「FAX 送信待ち」に宛先の FAX 番号と PDF を並べておき、人が印刷メニューから送る。送ったら「送った」を押す。
- **第2段階**：送る数が増えたら C を検討。承認ボタンのあとに、人がもう一度「送信」を押したときだけ送る形にする（承認なし・人の操作なしでは送らない、という決まりは守る）。

## 担当者にお願いすること（決めたあと）

- B にする場合：販売店（または社内の担当）に、ネットワーク FAX ドライバーの入手と、複合機側の設定の確認を頼む。**複合機の設定変更は、担当者の了承を取ってから行う。**
- C にする場合：サービスの選定と契約（課金が発生するので担当者の判断）。
