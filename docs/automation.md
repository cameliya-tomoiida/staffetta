# 自動化（⑤の分）

方針（11/5）：AI は値を書き換えない。迷わなかったもの・ふだんどおりのものは、人の確認を待たずに進める。自動で決めたものは「自動（…）」と記録され、取り消せる。ON/OFF は①の **機能の ON/OFF**（`/settings/features`、`src/lib/settings/features.ts` の import_auto_confirm・standing_auto_create・purchase_auto_approve・production_done_auto・order_reply_drafts・receipt_auto_receive）。既定は「人に聞く」（OFF）。時刻・上限金額・幅と記録は **自動化の設定**（`/settings/automation`）。

| # | 何を自動にするか | 人に回すとき | 記録 |
|---|---|---|---|
| A8 | シート・インフォマート・専用サイトの取り込み：全行の商品が辞書で決まり、締めに間に合う注文を確定。シートの変更は元の注文に反映 | 辞書に無い品・締めに間に合わない・元の注文が未確定 | 注文の confirmedBy「自動（辞書で全部決まった）」、元の行の edits「自動（変更を反映）」 |
| A9 | メール：全行の商品が決まり、印が無く、自信が設定以上（既定 0.9） | 印・自信が低い・キャンセル | 「自動（メールを迷わず読めた）」 |
| A11 | 定期注文：設定の曜日・時刻（既定 木 7:00）を過ぎたら次週分を作って確定 | 納品しない曜日は作らない（理由を記録） | 「自動（定期注文）」 |
| B1 | 発注書：過去4週の同じ曜日の平均 ±20% の量・初めてでない品・金額が上限（既定 5万円）以下なら承認。**送るのは人** | 外れた理由を記録 | approvedBy「自動（ふだんの量）」 |
| C3 | 製造の実績：設定の時刻（既定 22:00）を過ぎたら、その日を「計画どおり作った」で確定し在庫から引く | 人が先に記録していれば何もしない。違った品は「実績の数を直す」 | 「自動（計画どおり作った）」 |
| D1 | 返事が要る先の返事を送信待ちに。全行そのまま受けられるものは「そのまま送れます」。**送るのは人** | 変更・受けられない品があるものは「人が見てから送る」 | 送り出しの一覧 |
| B5 | 入荷：納品書（写真・PDF）を Claude で読み、発注書と全部合えば入荷 | 数が違う・読めない・発注書に無い品 | 「自動（納品書と一致・…）」 |

## 決まった時刻の仕事を動かすには
①の5分ごとの仕事から次を呼ぶ（送り出しの画面を開いたときにも動く）。同じ週・同じ日に2回は動かない。

```
curl -X POST http://localhost:3100/api/automation -H "content-type: application/json" -d "{\"action\":\"tick\"}"
```

自動で決めたこと・人に回したことは、自動化の設定の画面の下に並ぶ（`automation_log`）。
