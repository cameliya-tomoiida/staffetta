### 2回目の問題を直した（⑧の分・r3 に写真）
- 7. /settings → 設定の目次（ボタンの一覧だけ）を作った。`r3/settings-*`
- 9. demo:scale は流した日を基準に、今日と明日の注文を入れる（日付を渡せばその日だけ・`--fixed` で前の 11/6）。開く日を 11/6 に寄せるのは `DEMO_SHOW_DATE` を書いたときだけにした。製造のホームは「次に始める 20:27」・作っている帯・今の時刻の線が出る。`r3/home-factory-*`

- 1・2・6. 製品カード・衛生管理・定期注文の説明の文を消した（製品カード・衛生管理は題に重ねると出る）。`r3/cards-*`・`r3/hygiene-*`・`r3/standing-*`
