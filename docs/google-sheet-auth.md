# Google スプレッドシートの読み方（認証）

対象：得意先の本部が管理している注文シート。店舗別・月別のシートで、行＝納品日、列＝商品、セル＝ケース数。
ハブは「URL＋シート名＋範囲」を指定して読み、前回との差分を出す（`src/lib/channels/google_sheet/import.ts`）。

## 決めたこと（2026-11-04）

- **デモ：公開 CSV 出力**（「リンクを知っている全員が閲覧可」にしたシートを、ハブが CSV として読む）。
  - 今のコードのまま動く。架空のシートは `public/samples/inbound/sheet/` にもある（URL 欄に `demo:ファイル名`）。
- **本番ではサービスアカウント**にする（下の「本番では」）。

## デモでの使い方（公開 CSV）

1. 架空の注文シートを Google スプレッドシートで作る（中身は `public/samples/inbound/sheet/` の CSV と同じ形）。
2. 右上の「共有」→「一般的なアクセス」を「リンクを知っている全員」「閲覧者」にする。
3. ハブの `/import` 画面で、シートの URL・シート名（タブの名前）・範囲（空なら全部）・得意先 ID を入れて「このシートを読む」。
4. シートの数字を書き換えて、もう一度読むと、前回との差分が出る。

ハブは次の URL で読む（gviz の CSV 出力）：
`https://docs.google.com/spreadsheets/d/<シートID>/gviz/tq?tqx=out:csv&sheet=<シート名>&range=<範囲>`

## 本番では（サービスアカウント）

| | 公開 CSV | サービスアカウント（本番） |
|---|---|---|
| しくみ | 共有を「リンクを知っている全員が閲覧可」にする | Google Cloud で「ハブ専用のロボット用アカウント」を作り、シートをそのメールアドレスに共有する |
| 安全さ | URL が漏れると誰でも見られる | 共有した相手（ロボット）しか見られない |
| 先方へのお願い | 「リンクを知っている全員が閲覧可」にしてもらう | 「このメールアドレスに閲覧者として共有」してもらう |
| ハブ側 | 今のまま | `fetchGrid()` を Sheets API（spreadsheets.values.get）で読む形に差し替える |

本番に切り替えるときに担当者にお願いすること：
1. Google Cloud のプロジェクト作成画面を Claude が開いて準備する。担当者はログインと規約への同意だけを行う。
2. できたサービスアカウントのメールアドレスを先方に伝えて、閲覧者として共有してもらう（文面は Claude が下書きする）。
3. 鍵（JSON）は `.env.local` に入れる（公開リポジトリには入れない）。
