# Google スプレッドシートの読み方（認証）の選択肢

対象：ベーグル店本部（宅配の店A相当）の注文シート。店舗別・月別のシートで、行＝納品日、列＝商品、セル＝ケース数。
ハブは「URL＋シート名＋範囲」を指定して読み、前回との差分を出す（`src/lib/channels/google_sheet/import.ts`）。

どちらで読むかを、担当者に決めてもらう。

| | A. 公開 CSV（リンクを知っている人は閲覧可） | B. サービスアカウント |
|---|---|---|
| しくみ | シートの共有を「リンクを知っている全員が閲覧可」にして、ハブが CSV として読む | Google Cloud で「ハブ専用のロボット用アカウント」を作り、シートをそのアカウントのメールアドレスに共有する |
| 設定の手間 | 少ない（共有設定を1か所変えるだけ）。ただしシートの持ち主（先方の本部）に頼む必要がある | 多い（Google Cloud のプロジェクト作成・鍵の発行・ハブへの鍵の設定） |
| 安全さ | URL が漏れると誰でも見られる | 共有した相手（ロボット）しか見られない |
| 先方へのお願い | 「リンクを知っている全員が閲覧可」にしてもらう | 「このメールアドレスに閲覧者として共有」してもらう |
| ハブ側 | 今のコードのまま動く | Sheets API で読む部分を足す（小さな改修） |

## おすすめ

- **デモ**：架空のシート（`public/samples/inbound/sheet/`）で動かす。認証は不要。
- **本番**：**B（サービスアカウント）**。先方の注文データを公開せずに済むため。
  先方の本部がすでに GAS などで自動化しているので、「閲覧者として共有」のお願いは通りやすいと考えている【推】。

## B にした場合に担当者にお願いすること

1. Google Cloud のプロジェクト作成画面を、Claude が開いて準備する。担当者は Google アカウントでのログインと、規約への同意だけを行う。
2. できたサービスアカウントのメールアドレスを、先方の本部に伝えて共有してもらう（文面は Claude が下書きする）。
3. 鍵（JSON）は `.env.local` に入れる（公開リポジトリには入れない）。
