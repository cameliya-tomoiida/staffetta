# 工程表の精度：実際の1日と比べて（2026-11-05）

工場の資料（工程表・人員配置表・作業指示書・製造会議の要約・統合製造計画）から、ピザラインの「ある1日」を取り出し、
同じ注文をアプリに入れて工程表を比べました。取引先・個人の名前は伏せています。
数字そのもの（実データ）はリポジトリに入れず、本番の DB にだけ入れました（`scripts/import-real/` で取り込み）。

## 比べた日

- 実際：月曜。ピザクラスト 23cm を **約1,800枚**（ラインの1日の上限いっぱい）。
  - 前の日（1日目）：計量 → ミキシング → 1次発酵 40分 → 分割・丸め・箱取り（4人・1ロット400個を40分）→ 2次発酵（室温20℃・9時間、夜のあいだ）
  - その日（2日目）：**7:00〜24:00**。伸ばし・鉄板のせ（2人）→ ジェットオーブン（1人）→ ショックフリーザー（霜取り 17:00〜17:40 は使えない）→ 検品・包装・金属検査・梱包（1人）。ラインの最低は4人。
  - 班：朝班 2人 7〜18時、夜班 2人 13〜24時、スポットの人 7〜14時 2人・18〜21:30 1人・21〜24時 2人、学生 17〜22時 1人。
- アプリ：同じ生地・同じ1,800枚を、同じ納品日で計算（`scripts/import-real/day.ts`）。

## ずれ（直す前）

| | 実際 | アプリ（直す前） | ずれの理由 |
|---|---|---|---|
| 1日の長さ | 7:00〜24:00 | 8:00〜18:25（見本のマスタ）／ 8:00〜翌1:40（原価表の工程をそのまま入れた場合） | 下の3つ |
| 工程のつながり | **ロットごとに流れる**。伸ばした生地から順に焼き、冷やし、包む。全部の工程が同時に動いている | 1つの工程が全部終わってから次の工程（伸ばし3時間 → 焼成3時間 → 包装3時間…と縦に並ぶ） | 流れ作業の考えが無かった |
| 伸ばしの速さ | 2人で 1時間 約120枚（1,800枚を約15時間） | 見本は 4人で 1時間 600枚 | 見本の値が速すぎ。原価表の「人件費の基準」の時間は工程表の時間ではない |
| 人数 | 伸ばし2・焼成1・包装1 ＝ 4人 | 見本は 伸ばし4・包装3 → 人が足りない警告が多い | 配置人数を実際に合わせていなかった |
| 開始・設備の時間 | 7:00〜24:00 | 8:00〜18:00 の設備があった（本番の DB が古い見本のまま） | 古い見本のまま |
| 霜取り | 霜取りの40分は焼いたピザがラックで待つ | 「使えない時間にかかっています」の警告 | 流している途中に止まる、を表せなかった |

## 直したこと

1. **ロットで流す**（計算）：ラインに「流すロット（個）」を足しました（`LineMaster.lotSize`、マスタの列「流すロット（個）」）。
   入れると、当日の工程は「前の工程の最初のロットが終わったら次の工程を始める」「終わりは、前の工程の最後のロット＋1ロット分より後」で並びます。
   発酵・冷却など待つだけの工程は、ロットごとに同時に進みます。空なら今までどおり（見本・テストの結果は変わりません）。
2. **流している途中の止まり**（計算）：ロットで流す工程が設備の使えない時間帯（霜取り）にかかるときは、その分だけ止まって終わりが延びます。工程に「○分 止まる」と書き、警告にはしません。
3. **本番の DB の値**（データ。リポジトリの外）：ピザラインの開始 7:00・流すロット 40枚（ラック1台ぶん）、ピザの設備の時間 7:00〜24:00・霜取り 17:00〜17:40、班と配置人数（伸ばし2・焼成1・包装1）、23cm の生地の工程（工程表の時間：1ロット400個を分割40分・4人、2次発酵 9時間、伸ばし 1枚30秒 など）。

## 直したあと

| | 実際 | アプリ（直したあと） |
|---|---|---|
| 前の日 | 午後に仕込み → 夜のあいだ 2次発酵 | 13:00〜17:32 仕込み・分割 → 17:32〜翌2:32 2次発酵 |
| その日 | 7:00〜24:00 | **7:00〜23:36**（伸ばし 7:00〜22:00、焼成 7:20〜22:07、冷凍は霜取りで40分止まる、包装 〜23:31） |
| 人が足りない警告 | （足りている） | 出ない |

のこりのずれ（約25分）は、人が減る時間（12〜13時・17〜19時の休けい）に伸ばしをゆっくりにすること、最後の片付けの長さが資料に無いこと、です。

## まだ足りない考え（資料に数字が無いもの・これから）

| 考え | いま | 次にすること |
|---|---|---|
| 段取り替え・洗浄 | 工程ごとに「段取り・調整（分）」はあるが、**どの資料にも時間が書いていない**。商品が変わるときは責任者に声をかける、だけ | 現場で1回測る（生地が変わるとき・トッピングが変わるとき・終わりの洗浄）。生地が変わるときの段取りを、工程表の生地と生地のあいだに入れる |
| 休けいで人が減る | 班の人数は一定として見ている | 班に「休けい」の時間を持たせ、その時間は流れを遅くする |
| 冷凍庫の容量 | 見ていない（左の冷凍庫は約90ケースが上限、11月は外の倉庫も検討中） | 保管の工程に「冷凍庫のケース数」を持たせ、作りだめ（前の日に作っておく提案）と在庫の合計が上限を超えないか見る |
| 発酵の待ちの重なり | 前の日の仕込みは前日 13:00 から順に。発酵室・ラックの数は見ていない | ラック・発酵の場所の数を設備に入れる |
| ミキサー・分割機・オーブンの能力 | ミキサーの kg、オーブン1回の枚数は資料に無い（分割は「1分20個」のメモだけ） | 現場で測って設備のマスタに入れる |
| パンのライン | 逆算（納品時刻から）で組む。ロットで流す計算は前から組むラインだけ | パンにも 180〜240個のロットで流す計算を入れる（品質のために1ロット360個はやめた、という会議の決定に合わせる） |
| 資料どうしの食いちがい | 23cm の入数（20枚／40枚）、こね上げ（25℃／26℃）、冷却の基準（−20℃／−18℃）など | 工場長に確かめて、マスタを1つに決める |
