# LINE の注文フォーム（/liff/order）作り直しの仕様（担当者 11/7 夕方・管理役2がまとめ）

担当者の言葉（要点）:
「ホームページのアプリみたいに、下にサブメニューをカテゴリーごとに出して、注文を確定する形に。ホームはカレンダーと前回の注文だけ。『明後日からしか注文できません』のような文は書かない。締め時間を過ぎていたら、その日を選べなくするだけ。送る時に単価（ご注文単価）とロット（入数）も載せる。表みたいな形がいい。お客さんに出すにはひどい UI。機能性と見た目にちゃんとこだわって、もう一回作り直して」

対象: `src/app/liff/order/LiffOrder.tsx`（丸ごと作り直してよい）、`src/lib/channels/line/orders.ts` の `liffContext`（単価・入数・分類を返す）、必要なら商品マスタに `category`（分類）を足す。

## 画面の骨組み（下タブ 3つ・常に表示）

```
┌──────────────────────────────┐
│ ベーカリーカフェ ことり さま   │ ← 14px・薄い字。英字の飾りは無し
│ 11/9(月) お届け ▾            │ ← 選んだ日を1行で（タップでホームへ）
├──────────────────────────────┤
│                              │
│   （タブの中身）              │
│                              │
├──────────────────────────────┤
│  🏠ホーム   🍞商品   📋注文 ②  │ ← 下タブ 56px・アイコン 22px＋文字 11px・選んだ数のバッジ
└──────────────────────────────┘
```

### 1. ホーム
- 月のカレンダー（‹ 11月 ›）。マスは 40px 角、1か月で画面の半分以下。
- **選べない日はグレーで押せないだけ**。「あしたは締め切りを過ぎています」などの説明文は出さない。
  - 今日・過ぎた日 → 押せない
  - 締め時間（取引先の締め。無ければ商品の締め）を過ぎていたら → あしたも押せない（あさってから）
  - お届けのない曜日（定休日） → 押せない（「休み」の小さな字だけは残してよい）
  - 3か月先（92日）まで
- 日を押したら、その日が赤くなり、上の「11/9(月) お届け」が変わる。
- カレンダーの下に **前回の注文** の小さな箱：「前回 11/6(金)」＋ 商品と数を1行ずつ（表の形）＋ 右に「前回の数を入れる」ボタン（押すと数が入って、下タブの「注文」にバッジが付く。画面は動かない）。
- それ以外は何も置かない（説明文・「使いかた」は無し）。

### 2. 商品
- 上に **分類のタブ**（横に並ぶ・押した所に下線・画面上に固定）：`食パン｜ロール｜ピザ｜菓子・惣菜｜その他`。
  - 商品マスタに `category?: string` を足す（画面「商品」のマスタで選べる）。無い商品は名前で決める（「食パン」を含む→食パン、「ロール」→ロール、「ピザ」→ピザ、「サンド」「バンズ」「カレー」「メロン」→菓子・惣菜、それ以外→その他）。
  - 取引先ごとの商品（line_own_products ON・ひも付け済み）のときは、その取引先の商品だけを同じ分類で出す。分類が1つしか無いならタブは出さない。
- 商品の行（64px・1px の細い線で区切る）:
  ```
  [絵32px]  ピザクラスト 23cm            ( − ) 4 枚 ( + )
            ¥120 / 枚 ・ 5枚入            ← 13px 薄い字。卸価格が無ければ入数だけ、両方無ければ出さない
  ```
  - 数を入れると行の左に細い赤い線が付く（入っている商品が分かる）。
  - 「個で注文」のような文は出さない。単位は数の横だけ。
  - 数の入れ方: − ＋ と、数を押すと数字キーボードで直接入力（大きい数のため）。
- 締めを過ぎて間に合わない商品（リードタイム）は、行を薄くして「11/11 から」の小さな字（文は短く）。

### 3. 注文（確認）
- **表**（Excel のような、罫線のある表）:
  ```
  商品             数     単価     金額
  ピザクラスト 23cm  4 枚   ¥120    ¥480
  ピザ生地玉 180g   3 個   ¥ 90    ¥270
  ────────────────────────────────
  合計（税抜）                     ¥750
  ```
  - 単価＝取引先の卸価格（customerProducts.price）。無い商品は「—」。全部無ければ単価・金額の列ごと出さない。
  - 入数（ロット）は商品名の下に 12px で「5枚入」。
  - 税は出さない（税抜の合計だけ。「税抜」の2字は出す）。
- 表の上に「お届け日 11月9日（月）」。表の下に **「注文する」** の赤いボタン1つ。
- 数を直したいときは「商品」タブへ（この画面でも数を押せば直せるとなお良い）。
- 送ったあと: 同じ表に「受け付けました」の見出し。ボタンは「ホームへ」1つ。LINE のトークにも同じ内容が届く（今までどおり）。
- 履歴は「注文」タブの下に「これまでの注文 ›」の1行（押すと一覧。上に「‹ もどる」）。

## 見た目の決まり
- 文字: 見出し 20px・本文 15px・補足 13px・バッジ 11px。**22px を超える字はカレンダーの月名以外に使わない。**
- 色: 今の赤（crust-600）は「押す所」と「選んだ所」だけ。それ以外は黒・白・グレー 3段。飾りの英字（ORDER・HISTORY）・絵文字は使わない。
- 角丸 12px・線 1px・影なし。押した時に 0.98 倍に縮む。
- セーフエリア（iPhone の下の棒）の分だけ下タブの下に余白。
- ライト／ダークは LINE の設定（prefers-color-scheme）に合わせる。両方で写真を撮る。
- 参考にする密度: 台ヨミ（pa-main）のスマホ画面、ネットスーパー（イオン・楽天西友）の商品一覧。
