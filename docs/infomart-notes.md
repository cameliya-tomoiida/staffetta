## 1. 発注の入力画面（発注リスト ＝ マイカタログ）

- 流れは4段階：**① 数量を入力する → ② 納品日を入力する → ③ 確認画面 → ④ 完了**。
  - ① の画面で数量を入れて「納品日入力へ」を押す。③ で内容を見て、人が確定する。
- 画面のタブ：「発注」と「週間発注」。
- 一覧の列：**商品名／規格・入数／単位／単価／数量（＋−ボタン付きの入力欄。単位が横に出る）／取引先（締め時間）**。
  - 単位の例：C/S（ケース）、PC、袋、缶、本、kg、束、玉、個、箱。
  - 締め時間は取引先ごとに表示される（例「12:00締 翌日、22:00締 翌日」のように、1日に2回締めがある取引先もある）。
- 並び順は選べる：発注頻度の高い商品（初期）／更新日／登録日／商品名／商品名フリガナ／**取引先＞表示順**／入力した商品／通常品／非表示商品／**設定済表示順**。
  - → ハブの「入力用リスト」は、並び順を **「設定済表示順」または「取引先＞表示順」に固定して使う** のがよい（発注頻度順は日によって変わるため）。
- 絞り込み：通常品／非表示／リードタイム（D1〜D6以上）／商品分類（食材・その他）／規格書／キーワード。
- 登録されている商品は約60件。取引先は2社（A社：材料の卸。ほとんどの品目／B社：粉）。
- 一覧の「ダウンロード」（画面に出ている商品の一覧）と「印刷」がある。

## 2. CSV で出せるもの・入れられるもの

- **発注を CSV で一括取り込みする機能は、このアカウントの画面には見当たらなかった**（「設定・登録 → 外部データ連携」はダウンロードだけ）。
  - → 発注は「画面で数量を入れる」前提にする。ハブはサイトの並びどおりの入力用リストを出す。発注用の CSV は出さない。
- **取引ダウンロード**（取引の実績を CSV で出す）：
  - 出す内容は「ダウンロード設定」で選ぶ。用意されている形の例：取引明細、取引一覧、取引先別合計、取引明細（簡易版）、取引先別商品別集計 など。ファイルは CSV、レコードは「ブロック」、出力単位は「明細」。
  - 条件：対象日付（伝票日付・発注日・発送予定日・発送日・納品日・受領日・送信日・更新日）、日付の範囲（31日まで）、**「まだダウンロードしていない取引だけ」**、状態、取引区分、取引先、納品場所など。
  - **タスクスケジュール**：決まった条件のダウンロードを自動で実行できる。
- **マスタダウンロード**：登録されている商品マスタを CSV で出せる。
