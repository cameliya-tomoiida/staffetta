# マスタのサンプル CSV（架空データ）

「CSV で一括登録」のデモ用です。Excel で開いて、そのまま保存して読み込めます。

| ファイル | 画面 | 中身 |
|---|---|---|
| 仕入先マスタ_追加と変更.csv | /masters/suppliers | 1件更新（米田製粉の締め 15:00→14:00）・2件追加 |
| 材料マスタ_追加と在庫.csv | /masters/materials | 強力粉の在庫・最大在庫・保管場所の更新、3件追加（仕入先は名前でも ID でも書ける） |
| 材料マスタ_ShiftJIS.csv | /masters/materials | Excel が Shift_JIS で保存した CSV の例。中力粉・上白糖の在庫を更新 |
| 包材マスタ_追加.csv | /masters/packaging | 2件追加・賞味期限シールの在庫を更新 |
| 包材マスタ_エラーあり.csv | /masters/packaging | わざとエラーを入れた例（単位・仕入先・ロット・必須の在庫）。行番号と列名つきで出て、登録されない |
| 商品マスタ_追加.csv | 商品マスタ（③の列定義に合わせて直す） | 3件追加 |
| 取引先マスタ_追加.csv | 取引先マスタ（③④の列定義に合わせて直す） | 3件追加 |
| 設備マスタ.csv | 設備マスタ（③の列定義に合わせて直す） | ミキサー・分割機・ホイロ・オーブン・スライサー・金属検出機 |

仕入先・材料・包材の CSV は、`src/lib/masters/__tests__/samples.test.ts` で結果を確かめています。
