# マスタのサンプル CSV（架空の社名・数字は現場の実態に近づけたもの）

「CSV で一括登録」のデモ用です。Excel で開いて、そのまま保存して読み込めます。参照があるので、番号の順に読み込んでください。
社名は架空（仕入先A〜G・包材A〜C）。入数・ロット・リードタイム・保管場所は、社内資料（材料マスタ・包材発注依頼書・工程表）から実態に近い値にしました。

| ファイル | 画面 | 中身 |
|---|---|---|
| 01_仕入先マスタ.csv | /masters/suppliers | 米田製粉の締めを 15:00→12:00 に更新、仕入先A〜G・包材A〜C の10件を追加 |
| 02_仕入先の便.csv | /masters/supplierDeliveries | ふじみ製パン（デモ）の1便・2便（2便で受ける得意先）を更新、チーズの朝便を追加 |
| 03_材料マスタ.csv | /masters/materials | 強力粉の在庫・保管場所を更新、ピザ用の粉・チーズ・トマトなど15件を追加 |
| 04_包材マスタ.csv | /masters/packaging | ロール袋の在庫を更新、真空袋・台紙・ラベル・食パン袋・段ボールなど13件を追加 |
| 05_材料の在庫_ShiftJIS.csv | /masters/materials | Excel が Shift_JIS で保存した CSV の例。3つの材料の在庫だけを入れ直す（ほかの列は今のまま） |
| 06_包材マスタ_エラーあり.csv | /masters/packaging | わざとエラーを入れた例（使う＝たぶん・存在しない仕入先・ロットが文字・必須の空欄）。行番号と列名つきで出て、登録されない |
| 07_商品マスタ.csv | /masters/products | 3件追加（③の列名） |
| 08_取引先マスタ.csv | /masters/customers | 3件追加（③の列名） |
| 09_設備マスタ.csv | /masters/equipment | ミキサー・分割機・ジェットオーブン・ショックフリーザー・金属検出機（③の列名） |
| 10_便マスタ.csv | 便マスタ（/masters/courses） | 東コース（朝便）の出発と積み込みを直す（更新1）・北コースを足す（追加1） |
| 11_取引先の納品曜日.csv | 取引先（/masters/customers） | 「得意先ID・納品する曜日」の2列だけ。ほかの列は今の値のまま（更新2） |
| 12_定期注文.csv | 定期注文（/masters/standingOrders） | C07 に 月・水・金 のロール（追加4）。11 を先に入れてから「今週分を作る」 |

01〜06 の結果は `src/lib/masters/__tests__/samples.test.ts` で確かめています。
